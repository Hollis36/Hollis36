### Research focus

- **Robot programming with foundation models**: turning task descriptions into executable robot programs, and keeping slow LLM reasoning out of fast control loops.
- **Robust multimodal perception**: vision-language models as teachers and verifiers for object detectors.
- **Physics-informed AI for manufacturing**: simulation, process modelling and inspection for industrial robots such as spray painting.

### Selected projects

| Project | What it does | Links |
|---|---|---|
| [**TianWen**](https://github.com/Hollis36/TianWen) | Plug vision-language models into an object detector with one config file: distillation, feature fusion or decision-level verification. | [project page](https://hollis36.github.io/tianwen-project-page/) |
| [**abb-offline-coder**](https://github.com/Hollis36/abb-offline-coder) | Offline assistant that turns task descriptions into ABB RAPID spray-painting programs, with a local LLM and RAG over the official manuals. | [demo](https://hollis36.github.io/abb-offline-coder/) |
| [**newton-vla-demo**](https://github.com/Hollis36/newton-vla-demo) | A 3-minute embodied-AI demo on a laptop: Newton physics, natural-language pick and stack, dual-arm collaboration. | [live site](https://hollis36.github.io/newton-vla-demo/) |
| [**speculative-mechatronics**](https://github.com/Hollis36/speculative-mechatronics) | Commitment policies for physical actions under LLM latency: a fast coarse stage acts while a slow precise stage refines. | |
| [**voice-cmd-correction**](https://github.com/Hollis36/voice-cmd-correction) | Cheap, CPU-only correction of noisy voice commands for restricted-vocabulary robotics. | |
| [**robotic-manipulation-learning**](https://github.com/Hollis36/robotic-manipulation-learning) | Notes, derivations and runnable cases for robotic manipulation, with in-browser labs. | [book](https://hollis36.github.io/robotic-manipulation-learning/) |
