# Embodied AI × Industrial Automation

Research and open-source work where embodied AI meets industrial automation: foundation models for robot programming and inspection, robust multimodal perception, and physics-informed AI for manufacturing.

## Projects

- [**TianWen**](https://github.com/Hollis36/TianWen): plug vision-language models into an object detector with one config file · [project page](https://hollis36.github.io/tianwen-project-page/)
- [**abb-offline-coder**](https://github.com/Hollis36/abb-offline-coder): an offline assistant that turns task descriptions into ABB painting-robot RAPID programs · [demo](https://hollis36.github.io/abb-offline-coder/)
- [**newton-vla-demo**](https://github.com/Hollis36/newton-vla-demo): a 3-minute embodied-AI demo on a laptop, with Newton physics and an LLM as the VLA brain
- [**speculative-mechatronics**](https://github.com/Hollis36/speculative-mechatronics): commitment policies for physical actions under LLM latency
- [**voice-cmd-correction**](https://github.com/Hollis36/voice-cmd-correction): cheap, robust correction of noisy voice commands for restricted-vocabulary robotics
- [**robotic-manipulation-learning**](https://github.com/Hollis36/robotic-manipulation-learning): notes, derivations and runnable cases for robotic manipulation
