# Hi, I am Hollis36

I work on **multimodal perception**, **industrial embodied intelligence**, **robot learning**, and **AI systems for smart manufacturing**. My current interests focus on robust visual sensing, RGB-T / RGB-D fusion, UAV and anti-UAV perception, vision-language-action models, and deployable AI workflows for robotics and industrial scenarios.

## Research Interests

- Multimodal perception and sensor fusion
- RGB-T / infrared-visible object detection
- UAV and anti-UAV intelligent sensing
- Vision-language and vision-language-action models
- Robot learning and embodied intelligence
- Smart manufacturing, industrial inspection, and digital twins
- AI for scientific and engineering systems

## Selected Projects

### DroneVehicle

Multimodal UAV-view vehicle detection with visible-infrared perception. This project explores robust vehicle detection under small-object scale variation, background clutter, and cross-modality sensing conditions.

### smolvlm-anti-drone

Lightweight vision-language reasoning for anti-drone perception. This project studies whether small VLMs can help with target verification, false-positive reduction, and explainable anti-UAV sensing.

### VLM-UAV

Vision-language models for UAV perception and semantic scene understanding. This project focuses on UAV-specific VLM tasks, open-vocabulary reasoning, detector-VLM collaboration, and reliability analysis.

### robot-sim-vla-experiments

Simulation experiments for robot learning and vision-language-action models. This project supports embodied-intelligence experiments before real-robot deployment.

### abb-offline-coder

Offline programming and code-generation tooling for ABB industrial robots. This project connects process planning, robot execution code, and industrial deployment workflows.

### robotic-manipulation-learning

Robot manipulation learning and embodied AI experiments for perception-action systems.
